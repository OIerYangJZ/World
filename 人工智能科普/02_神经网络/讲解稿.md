## 大纲

**核心问题**：要识别手写数字这种“写不出规则”的东西，黑箱里该装一个什么样的函数？

**一句话答案**：神经网络就是很多“神经元”分层连接；每个神经元只做一件简单的事：把输入**加权求和、加偏置，再过一个非线性开关**。简单的单元一层层叠起来，就能拼出极其复杂的函数。

## 节拍与字幕规则

- 一小节 = 240 / 96 = 2.5 秒；第 n 小节起点 = (n − 1) × 2.5 秒。主歌、副歌、尾声每句 **2 小节**（5 秒），桥段每句 **4 小节**（10 秒）。
- BPM 较快，按规划 2.1 把主歌二、主歌三加到 20 小节，总时长落在 5–6 分钟。
- 字幕**在小节线上切换，不做提前量**；ASS 起止取整到帧（30 fps），与动画同一套帧网格。成片帧数 = 325 × 30 = **9750 帧**，构建脚本逐帧核对。
- 阅读速度：全部歌词 ≤ 4.6 字/秒（`common/beat.py` 自动校验，本集无超速句）；最快一句“一个神经元看全部 784 个像素，各有各的权重” 20 字 / 5 秒 = 4.0 字/秒。

## 画面设计说明

- **常驻元素**：左上角段落提示；右上角旋钮计数器（本集 2 → 13,002，在主歌三第 77–78 小节滚动）。
- **手写数字**：画面里的“7”和数字墙都是 `common/digits.py` 程序生成的“手写风格”28×28 灰度图（折线笔画 + 随机倾斜 / 缩放 / 粗细），**不是 MNIST 原图**，画面上已注明“示意”。
- **网络示意**：784-16-16-10。输入列只画 16 个代表节点（中间用省略号），代表全部 784 个输入；连线颜色 = 权重正负（黄正、蓝负），粗细 = 大小，权重为随机示意值。
- **“判为 7”**：第 71 小节输出层“7”最亮，画面注明“示意：假设旋钮已经训练好”；尾声里旋钮随机时，10 个输出亮度差不多（乱猜）。
- **单个神经元的算式**：输入 0.9 / 0.1 / 0.7 / 0.0，权重 +0.8 / −0.5 / +0.3 / +1.2，加权和 = 0.72 − 0.05 + 0.21 + 0 = 0.88；偏置 −0.3 → 0.58；ReLU(0.58) = 0.58；ReLU(−0.4) = 0。
- **桥段 · 线性叠加**：平面网格先后经过两个线性变换 A、B，网格线始终是直线且平行；两步的效果等于一次变换 B·A。
- **桥段 · 对折**：蓝点在 |x| + |y| < 0.85 的菱形内，红点在 1.35 < |x| + |y| < 2.05 的环带里，任何一条直线都分不开。把 x < 0 的点对折到右边（x → |x|），再把 y < 0 的点对折到上边（y → |y|），所有点落到第一象限，直线 x + y ≈ 1.15 就能分开。画面角落注明 |x| = ReLU(x) + ReLU(−x)，即“一次对折 = 两个 ReLU 开关”。
- **万能逼近**：目标曲线 f(x) = 0.9·sin(1.3x) + 0.25x，用 2、5、20 段等距折线插值去拼；k 段折线需要 k − 1 个折点，每个折点对应一个 ReLU 神经元。
- **生物神经细胞**：抽象示意（胞体 + 分叉树突 + 轴突），不是解剖图。
- **“希望 vs 实际”**：“希望”里的笔画图（横、斜竖、圈）是手工画的；“实际”里的权重图是平滑后的随机噪声，示意“训练出的隐藏层权重往往杂乱、不好解释”，不是某个真实网络的权重。

## 二次审读记录

- “够亮才点明”（副歌）：对应 ReLU 的“总和超过 0（即超过由偏置决定的门槛）才有输出”，与画面门槛表一致；ReLU 输出是连续亮度而非开 / 关两档，主歌二第 43 小节“输出的数就是亮度，越大灯越明”已说明。
- “每根连线一个权重，就是一个旋钮”：与第 01 集“参数 = 旋钮”一致；偏置也是旋钮（第 39 小节），所以第 73 小节“每根连线、每盏灯都要算清”。
- “第一层就一万两千多，后面两层只是零星”：12,560 vs 272 + 170，表述准确。
- “缠在一起的两团点”：画面数据是菱形 + 环带，而非螺旋（螺旋需要更多次折叠，5 秒内讲不清），规划里的“例如两条交织的螺旋”为举例，不影响结论。
- “训练好后”：本集未讲训练，第 105–107 小节都把“怎么训练”留给第 03、04 集。
- 未说“神经网络模拟了人脑”；桥段、主歌四都用“受启发 / 比喻”。
