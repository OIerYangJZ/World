# 词向量：把文字变成一串数字

- 系列：人工智能科普 · 一层层打开黑箱（正片第 05 集，发布序 6）
- 时长：122 小节 × 240/90 秒 = **5:25.33**（325.333 秒），成片逐帧对齐小节网格（9760 帧）
- 形式：16:9，1920×1080，30 fps；**静音成片**（无音轨），只烧录说唱字幕；说唱人声由作者按同一 BPM 用 ACE 生成后合成
- 曲风：**jazz rap，90 BPM**，4/4 拍；walking bass + 钢琴 / 小号采样，轻快、文艺，配合“词语住在空间里”的点云画面

## 大纲

**核心问题**：神经网络只会算数字，它怎么“读”文字？

**一句话答案**：先把文字切成一小块一小块的 token（中文常译“词元”），每个 token 对应一个很长的数字列表（向量），可以看成高维空间里的一个点。训练会让意思相近的词靠在一起，甚至让某些“方向”带上含义。

## 节拍与字幕规则

- 一小节 = 240 / 90 ≈ 2.6667 秒；第 n 小节起点 = (n − 1) × 240 / 90 秒。主歌、副歌、尾声每句 **2 小节**（约 5.33 秒），桥段每句 **4 小节**（约 10.67 秒）。
- 字幕**在小节线上切换，不做提前量**；ASS 起止取整到帧（30 fps），与动画同一套帧网格。成片帧数 = 325.333 × 30 = **9760 帧**，构建脚本逐帧核对。
- 阅读速度：全部歌词 ≤ 4.6 字/秒（`common/beat.py` 自动校验，本集无超速句）；最快几句 20 字 / 5.33 秒 = 3.75 字/秒。

## 画面设计说明

- **常驻元素**：左上角段落提示；右上角旋钮计数器（“13,002” → 主歌二第 41 小节变成“6.2 亿”，表示 GPT-3 的嵌入表这一块旋钮）。
- **切分示意**：“床 / 前 / 明月 / 光”、“我们 / 的 / 今天 / 天气”、“龘 → 3 个字节片段”、“unbelievably → un / believ / ably”、“strawberry → str / aw / berry”都是**示意切法**，画面已注明“不同模型切法不同”。字节级分词器（如 GPT-2 的）会把罕见汉字拆成它的 UTF-8 字节（常见汉字 3 个字节）。
- **编号**：#30586、#14581、#1873、#1874 等都是示意编号，不是任何真实分词器的编号。
- **向量数值**：数字条里的 +0.12、−0.83 等以及嵌入表、热力格子的颜色都是随机示意值（黄 = 正，蓝 = 负）。
- **12,288**：GPT-3（1750 亿参数版本）的向量长度；画面上只画了 60 个格子，并注明“不同模型不一样”。
- **嵌入表规模**：GPT-3 词表 50,257 × 维度 12,288 = 617,558,016 ≈ 6.2 亿个数，占 1750 亿参数的约 0.35%；长条图按比例画，嵌入表那一条只有约 0.04 个单位宽，所以加了一个放大圈。
- **点云**：四团词（动物、食物、城市、电器）的位置是手工设计的三维示意坐标，用自写的正交投影画出并可转动；间奏一里点从随机位置移动到这些位置，示意“训练让意思相近的词靠近”。画面注明“真实向量有上千维，这里画成三维”。
- **类比平行四边形**：男人、女人、国王、女王，以及法国、意大利、巴黎、罗马的位置是示意坐标；“国王 − 男人 + 女人”的落点故意画在“女王”附近而不是正好重合，配文“最接近”；注释卡说明 word2vec、排除输入词、并非每次都成立。
- **“苹果”**：水果和手机都用简单几何图形，不使用任何品牌标志；同一个点被“食物”和“电器 / 科技”两团拉扯，为第 06 集埋悬念。
