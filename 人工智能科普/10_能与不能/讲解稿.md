## 大纲

**核心问题**：理解了原理之后，我们该怎么看待 AI：它为什么会一本正经地说错话？它是怎么查资料、用工具的？我们真的懂它吗？

**一句话答案**：它是一台极其强大的“下一个 token 预测器”，经过后训练成为助手：会编出看似合理的错话（幻觉），知识停在训练截止的那一天，对话里的“记忆”只是上下文；可以通过输出约定格式的指令来调用搜索、计算器、代码等工具；而它内部千亿个旋钮合起来究竟在算什么，人类才刚刚开始看懂。

## 节拍与字幕规则

- 一小节 = 240 / 84 ≈ 2.8571 秒；第 n 小节起点 = (n − 1) × 240 / 84 秒。主歌、副歌每句 **2 小节**（约 5.71 秒），桥段每句 **4 小节**（约 11.43 秒），尾声回顾句每句 **1 小节**（约 2.86 秒，正片唯一允许快嘴的地方，内容都是已讲过的知识）。
- 段落结构：84 BPM 偏慢，按规划 2.1 节去掉第二段器乐间奏，只保留第 47–50 小节一段；尾声加长到 14 小节容纳“一集一小节”的回顾，片尾 2 小节器乐放番外预告卡。总长正好 6:00。
- 字幕**在小节线上切换，不做提前量**；ASS 起止取整到帧（30 fps），与动画同一套帧网格。成片帧数 = 360 × 30 = **10800 帧**，构建脚本逐帧核对。
- 阅读速度：全部歌词 ≤ 4.6 字/秒（`common/beat.py` 自动校验，本集无超速句）；2 小节句阅读量 ≤ 24（最快第 17 小节约 4.2 字/秒），1 小节回顾句 ≤ 11（约 3.9 字/秒）。

## 画面设计说明

- **常驻元素**：左上角段落提示；右上角旋钮计数器“1750 亿”。主歌二第 31 小节计数器闪一下并出现一把锁（“训练结束 → 定格”）；尾声计数器从“2”按集滚到“1750 亿”（13,002 → 6.2 亿 → 586 亿 → 1750 亿，与前几集一致），最后定格。
- **背过与泛化**：“床前明月光”是训练文本里反复出现的名句，模型多半“背过”；“用‘霜’字写一句关于手机的诗 → 手机屏光冷如霜”是示意的新问题与回答，说明没见过的问题也能组合出合理回答（泛化）。
- **冷门问题与幻觉**：“1923 年某小镇的镇长是谁？”和回答“王德明，任期三年”是虚构示意；参考文献卡（作者、标题、期刊、卷期页码）全部为**虚构**，画面明确标注“虚构示意”。放大镜扫过后逐项打叉，卡片碎成像素。全片用“幻觉”“说错”“编”描述，并在画面注明“幻觉 ≠ 故意”，不用“撒谎 / 谎言”一类带意图的词。
- **评分表**：答对 1 分、答错 0 分、“不知道”0 分 → 只看得分时，猜一猜的期望分更高。注明这是近年研究提出的**原因之一**（Kalai 等，OpenAI，2025）。
- **记忆**：每一轮提问时，整段聊天记录（蓝 = 用户、绿 = 助手）一起飞回模型输入端；旋钮面板全程不动。上下文窗口长条只示意“有上限”，超出后的处理方式因产品而异（截断、压缩等）。“摘要便签”示意有些产品的跨对话记忆：存下摘要、下次放回上下文，旋钮依然没变。
- **工具调用**：工具卡写作“〔调用 计算器：37×89〕”，是示意格式；真实系统的格式各不相同，但原理一样：模型生成约定格式的文本 → 程序识别并执行 → 结果贴回上下文 → 模型继续生成。37 × 89 = 3293。工具调用前模型写出的错误数字为示意。
- **智能体**：循环图“想 → 调用工具 → 看结果 → 再想”，任务清单逐项打勾；画面小字注明每一步仍可能出错。
- **桥段**：一大片数字代表全部参数，每个都能读出来（“看得见”）；问号代表“合起来在算什么”还没完全看懂。
- **可解释性**：神经元一排、箭头方向、五根箭头挤在二维平面里（叠加的玩具示意，参考 Elhage 等 2022 的玩具模型）；稀疏自编码器把一个向量拆成一长排特征，只有少数几个非零。特征标签墙上的标签是该研究报告过的特征类型示意。金门大桥画成简笔几何桥（不使用任何照片或标志），出处在画面上写明：Anthropic《Scaling Monosemanticity》（2024）；“放大特征后回答绕到大桥上”依据该研究及其公开演示，画面中的问答为示意。
- **尾声回顾长镜头**：十格画面依次从右侧滑入中心再退到左侧：散点直线 → 网络灯阵 → 下山小球 → 红色反向流 → token 与向量 → 注意力探照灯 → 高塔与概率条（“霜”最高）→ 书架 → 旋钮偏转 → 问号 / 工具 / 特征。随后十格缩小连成一条链，“霜”从链的出口落下，第 01 集的黑箱最后一次打开。
- **片尾**：番外预告卡（番外三 多模态、番外四 扩散模型、番外五 文本水印），全部淡出。
