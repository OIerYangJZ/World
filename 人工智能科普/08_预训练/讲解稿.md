# 预训练：读遍互联网

- 系列：人工智能科普 · 一层层打开黑箱（正片第 08 集，发布序 9）
- 时长：122 小节 × 240/86 秒 = **5:40.47**（340.465 秒），成片逐帧对齐小节网格（10214 帧）
- 形式：16:9，1920×1080，30 fps；**静音成片**（无音轨），只烧录说唱字幕；说唱人声由作者按同一 BPM 用 ACE 生成后合成
- 曲风：**管弦史诗说唱，86 BPM**，4/4 拍；弦乐、铜管、合唱铺底，体现“读遍人类文字”的规模
- 主韵：姑苏辙（u）：数、处、读、目、步、簿、路、录、书、出、涂、布、夫、谱、足、铺、楚、住、肚
- 风格：深色背景、几何动画；颜色语义见 `规划.md` 1.5（蓝 = token，金 = 数据 / 书 / 答案，红 = 损失 / 误差，绿 = 正确 / 算力，紫 = 注意力，青 = 前馈）

## 大纲

**核心问题**：没人告诉模型“正确答案”，它怎么学会语法、常识、翻译、写代码？

**一句话答案**：预训练的任务只有一个：在海量文本上猜下一个 token。文本自己就是答案，不需要人工标注。要把下一个词猜得足够准，模型不得不学会语法、事实和一定的推理套路。规模（参数、数据、算力）越大，猜得越准，而且这种提升相当有规律。

## 节拍与字幕规则

- 一小节 = 240 / 86 ≈ 2.7907 秒；第 n 小节起点 = (n − 1) × 240 / 86 秒。主歌、副歌、尾声每句 **2 小节**（约 5.58 秒），桥段每句 **4 小节**（约 11.16 秒）。
- 字幕**在小节线上切换，不做提前量**；ASS 起止取整到帧（30 fps），与动画同一套帧网格。成片帧数 = round(340.465 × 30) = **10214 帧**，构建脚本逐帧核对。
- 阅读速度：全部歌词 ≤ 4.6 字/秒（`common/beat.py` 自动校验，本集无超速句）；每句 ≤ 21 字（2.2 节对 86–90 BPM 的建议是每小节 8–11 字），最快约 3.8 字/秒。

## 画面设计说明

- **常驻元素**：左上角段落提示；右上角旋钮计数器“1750 亿”（第 45 小节闪一下，配一行字“旋钮的数量早就超过了 1000 亿，而每一个都是被‘猜下一个词’这个任务调出来的”）。
- **遮挡猜词**：例句“今天 / 天气 / 很 / 好 / ， / 我们 / 去 / 公园 / 散步 / 。”（示意切分），遮挡块从左往右滑，每到一个位置弹出“下一个是？”。第 13 小节示意猜“冷”、答案“好”，产生损失并反向传播。
- **读书估算**：15×10¹² ÷ 300 ÷ 525,600 ≈ 95,100 年，画面写“约 9.5 万年”并注明“数量级估算”和全部假设（每分钟 300 个 token、不吃不睡不停、15 万亿 token）。
- **GPU 方阵**：256 个方格示意“上万块 GPU”，标注“最大的模型”“数周到数月”。
- **数据比例尺（间奏一）**：一本书 → 书架 → 图书馆 → 40 座图书馆，标注“示意”，不代表真实数量比例。
- **规模定律图**：双对数坐标（横轴算力、纵轴误差），6 条学习曲线由小模型到大模型，下包络为直线；曲线形状为示意，标注“（示意）”。
- **U 形曲线**：同样算力下，模型太小或太大（数据太少）误差都更高，最低点表示参数和数据配比合适；示意。
- **外推图**：实测范围内为实线，范围外为虚线 + 问号，强调经验规律有适用范围。
- **续写示例**：“1. 法国的首都是哪里？ → 2. 德国的首都是哪里？ 3. 意大利的首都是哪里？”与另一种续写“法国的首都是巴黎。”都是示意。
- **涌现对比图**：左图按“全对才算对”计分，曲线在某个规模处陡升；右图对同一组模型换成连续计分，曲线平滑上升。两图均为示意。
