# Transformer：一次只猜下一个词

- 系列：人工智能科普 · 一层层打开黑箱（正片第 07 集，发布序 8）
- 时长：130 小节 × 240/100 秒 = **5:12.00**（312.000 秒），成片逐帧对齐小节网格（9360 帧）
- 形式：16:9，1920×1080，30 fps；**静音成片**（无音轨），只烧录说唱字幕；说唱人声由作者按同一 BPM 用 ACE 生成后合成
- 曲风：**big beat 电子 funk，100 BPM**，4/4 拍；厚重的 breakbeat + funk 贝斯 + 合成器，“组装完成、机器启动”的能量
- 主韵：灰堆辙（ei / ui）：位、对、回、味、配、堆、尾、推、追、费、汇、类、随、谁、队、飞、会、脆、退
- 风格：深色背景、几何动画；颜色语义见 `规划.md` 1.5（紫 = 注意力，青 = 前馈，蓝 = token / 残差流，黄 = 向量 / 旋钮，绿 = 每层加的修改，金 = 概率 / 选中的 token，橙 = 温度）

## 大纲

**核心问题**：把注意力组装起来之后，聊天机器人到底是怎么“说话”的？

**一句话答案**：Transformer 就是“注意力层（词和词交流）+ 前馈层（每个词自己消化）”这一对组合，叠几十到上百层。最后一层输出下一个 token 的概率，挑一个接上，再把整句话送回去猜下一个。所有回答都是这样一个 token 一个 token 地长出来的。

## 节拍与字幕规则

- 一小节 = 240 / 100 = 2.4 秒；第 n 小节起点 = (n − 1) × 2.4 秒。主歌、副歌、尾声每句 **2 小节**（4.8 秒），桥段每句 **4 小节**（9.6 秒）。
- BPM 较快，按规划 2.1 把主歌二、主歌三加到 20 小节，总时长 5:12。
- 字幕**在小节线上切换，不做提前量**；ASS 起止取整到帧（30 fps），与动画同一套帧网格。成片帧数 = 312 × 30 = **9360 帧**，构建脚本逐帧核对。
- 阅读速度：全部歌词 ≤ 4.6 字/秒（`common/beat.py` 自动校验，本集无超速句）；最快一句 19 字 / 4.8 秒 ≈ 3.96 字/秒（2.2 节对 96–102 BPM 的建议是每小节 7–10 字，即每句 ≤ 20 字）。

## 画面设计说明

- **常驻元素**：左上角段落提示；右上角旋钮计数器（“586 亿” → 主歌二第 49 小节滚到“1750 亿”）。586 亿 = 嵌入表 + 注意力层（第 06 集），再加上前馈层约 1160 亿，就是 GPT-3 的约 1750 亿。
- **塔**：每个块 = 下层紫色“注意力” + 上层青色“前馈”（实际模型里每个子层前后还有层归一化，片中省略）。高塔为示意，标注“GPT-3：96 层”。
- **残差流**：三条传送带（“疑 / 是 / 地上”）穿过五层；中间那条上的黄色向量每穿过一层就首尾相接一支绿色小箭头（这一层加的修改），合成方向一点点偏转。示意二维向量，真实为 12,288 维（GPT-3）。
- **参数构成条**：按比例画：嵌入约 6.4 亿（含位置嵌入）、注意力约 580 亿、前馈约 1160 亿；注明计算方式（每层注意力约 4 × 12,288²，前馈约 8 × 12,288²，共 96 层）。
- **前馈层与事实**：“记忆格”与“埃菲尔铁塔位于 → 巴黎”的概率变化为示意，旁边注释卡写明“研究中的一种解释，不是定论”。
- **概率**：“霜 0.86、上 0.04、雪 0.03、面 0.03、光 0.02、白 0.02”，以及“窗外的雨下个不 → 停 0.52、住 0.18……”都是示意数值；分数（9.1、6.2……）也是示意。
- **桥段**：两句诗的 token 一个个出现（切分为示意）。
- **自回归**：句尾依次接上“霜”“。”“举”“头”，最后冒出“〈结束〉”token。
- **温度**：概率按 p^(1/T) 重新归一化（等价于把打分除以 T 再做 softmax）；T 从 1 调到 0.4（更尖），再到 3.5（更平）。
- **两次生成**：“窗外的雨 / 下个不停，像在敲门”与“窗外的雨 / 轻轻落下，湿了窗台”为示意。
- **上下文窗口**：44 个格子代表一长串 token，黄色窗口代表能看到的范围；标注 GPT-3 为 2048 个 token。

- 主歌二“GPT-3 有 96 层”“向量是一万两千多维”与第 49 小节“1750 亿”：都限定为 GPT-3，画面注明很多新模型不公开参数量（规划红线）。
