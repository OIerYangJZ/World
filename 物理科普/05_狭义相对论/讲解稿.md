### 第一章 光速之谜
1. 车速10米/秒，向前扔出20米/秒的球，站台上看球速是30米/秒。
2. 麦克斯韦方程组却给出：光速是定值c，约30万千米/秒。
3. 人们猜想光在“以太”中传播，可1887年迈克耳孙–莫雷实验没测到以太风。
4. 1905年，爱因斯坦提出两条假设。一：物理定律在所有惯性系中相同；
5. 二：真空中的光速对所有惯性观察者都是c，与光源运动无关。
6. 要保住光速c，时间和空间必须让步。

**画面**：一列火车（车厢+车轮）沿轨道匀速右行，车上小人把球向前抛出；车速、球相对车速、球相对地速三支箭头分别标注，箭头头尾相接展示 u = u′ + v（标注“低速近似”）。随后画面切换为向右传播的电磁波（E、B 正交正弦），旁边出现 c = 1/√(μ₀ε₀)。以太：背景淡色“以太风”流线，迈克耳孙干涉仪示意（光源、分束镜、两臂、探测器），条纹预期移动 0.4 条（虚线）而实测几乎不动。两条假设以两张卡片呈现，第二条配“运动光源发出的光仍以 c 前进”的小动画；最后 “c + v” 被划掉，换成 “c”。

### 第二章 时间膨胀
7. 光钟：光子从一面镜子飞到另一面（单程）算一次嘀嗒，用时Δτ = L/c。
8. 让光钟以v运动：地面看来光子走斜线，路程更长，而光速仍是c。
9. 斜边cΔt，底边vΔt，竖边L = cΔτ。用勾股定理：
10. 解出Δt = γΔτ：运动的钟慢了γ倍。
11. γ叫洛伦兹因子：0.87c时约为2，趋近光速时趋于无穷。
12. 在地面看来，飞船里的一切过程都同样变慢，包括心跳。
13. 而且是相互的：飞船上的人也看到地面的钟变慢。
14. μ子：宇宙射线在约15千米高空产生，静止寿命仅2.2微秒。
15. 若无时间膨胀，平均只能飞约660米，穿过大气只剩约百亿分之一。
16. 实际上γ≈16，寿命延长到约35微秒，约四分之一能抵达地面。
17. 加速器中的μ子、环球飞行的原子钟，也都验证了时间膨胀。

**画面**：左侧静止光钟，光子上下弹跳并计数；右侧同一光钟以 v = 0.6c 右移，光子留下锯齿形轨迹（TracedPath）。冻结第一段斜线，高亮直角三角形（3:4:5，对应 β = 0.6），三边标注 cΔt、vΔt、L = cΔτ，并注“垂直于运动方向的长度不变”。三角形移到左侧，右侧用 TransformMatchingTex 逐步推导：(cΔt)² = (vΔt)² + (cΔτ)² → Δt²(c² − v²) = c²Δτ² → Δt = Δτ/√(1−v²/c²) = γΔτ。γ(v/c) 曲线，ValueTracker 驱动的点沿曲线滑动、读数实时更新，v/c = 1 处画渐近虚线，标记 (0.866, 2)。两只表盘：静止表与运动表（γ = 2）指针转速不同；再交换视角展示相互性。μ子：左右两根大气柱（15 km 高度刻度），各 40 个 μ子从顶部同时落下，按指数分布（左：平均 0.66 km；右：平均 10.4 km）衰变后变灰停在原处，柱顶标题处显示抵达地面数（左 0，右 9/40）。随后两张证据卡：CERN μ子储存环（环上粒子绕行，γ ≈ 29.3，寿命 2.2 → 64 μs），Hafele–Keating 1971（地球与东西两向航线，实测 −59 ns / +273 ns）。

### 第三章 长度收缩与同时性
18. 可在μ子自己看来，它的钟并没变慢。
19. 答案：运动的物体沿运动方向缩短，L = L₀/γ。
20. μ子看到的大气只有约950米厚，结果一致。
21. 车厢中央闪光：车厢里看，光同时到达前后壁。
22. 站台上看：后壁迎光而来，前壁背光而去，后壁先亮。
23. 一个参考系里的“同时”，在另一个参考系里并不同时。

**画面**：一根静止的尺（长度 L₀）与一根运动的尺，ValueTracker 控制 β，运动的尺沿运动方向收缩、高度不变，读数 L/L₀ = 1/γ。随后在 μ子参考系中，15 km 的大气柱压扁成约 0.95 km 的薄层迎面上冲，μ子在其寿命内穿过。同时性：上下两个面板，上为“车厢参考系”（车厢静止，两道光前同时到达两壁，两壁同时闪亮），下为“站台参考系”（车厢以 0.5c 右移并按 1/γ 收缩，光前以 c 相对站台传播，后壁先亮、前壁后亮）；在站台面板上标注事件时间 t后 < t前，并注明“已扣除光传到观察者的时间”。

### 第四章 时空图与双生子
24. 时空图里，静止物体的世界线是竖线，光走45°斜线。
25. 运动观察者的时间轴和空间轴，都向光线倾斜。
26. 洛伦兹变换像一把剪刀：网格沿光线一拉一压，光线纹丝不动。
27. 原本同时的两个事件，在新坐标里一先一后。
28. 所有人都同意的量：时空间隔 s² = (cΔt)² − Δx²。
29. 变换只让事件沿着间隔不变的双曲线滑动。
30. 类时事件的先后永不颠倒；类空事件顺序可变，但它们无法相互影响。
31. 双胞胎之一以0.8c飞往4光年外的星球，再返回地球。
32. 地球上过了10年，旅行者的钟只走了6年。
33. 旅行者也能说是地球在动？关键：他掉头时换了惯性系，世界线是折线。
34. 世界线的长度就是固有时：两事件之间，直线最长。

**画面**：闵可夫斯基图（x 横、ct 纵），淡色静止网格、黄色 45° 光线、静止物体的竖直世界线、运动飞船的倾斜世界线。ValueTracker β 从 0 增至 0.5，飞船的 ct′、x′ 轴像剪刀一样向光线合拢，并带出其斜网格。随后做“主动变换”：整个图沿光线方向一拉一压（洛伦兹 boost），飞船网格被掰正、原网格变斜，光线不动；x 轴上两个同时事件 A、B 在新坐标中分开到不同高度（水平虚线读出时间）。右侧出现间隔公式；画出 s² = 2.25 的类时双曲线与类空双曲线，事件 C 与 A、B 在 β 来回扫动时沿各自双曲线滑动：C 始终在原点上方（光锥内，顺序不变），A、B 的先后随 β 的符号翻转（光锥外）。双生子：时空图中地球世界线竖直，每年一个刻度；旅行者世界线是到 (4 光年, 5 年) 的折线，每过 1 年固有时打一个刻度（共 6 个）；计数器同步走动。掉头处高亮，画出旅行者掉头前后两条“同时线”（与地球世界线交于 1.8 年与 8.2 年），提示视角跳变。最后标出每条腿的“闵氏长度”：√(5² − 4²) = 3 年，总计 6 年 < 10 年。

### 第五章 质能与速度极限
35. 能量与动量也合为一体：E² = (pc)² + (mc²)²。
36. 静止时p = 0，剩下E = mc²：质量本身就是能量。
37. 1克质量的静能约9×10¹³焦耳。
38. 能量E = γmc²：越接近光速越趋于无穷。
39. 所以有质量的物体永远到不了光速；光子没有质量，只能以c运动。
40. c不只是光速，而是时空的速度上限——因果传播的极限。

**画面**：直角三角形助记（直角边 pc 与 mc²，斜边 E），p 由 ValueTracker 控制；p → 0 时三角形收成竖线 E = mc²。E/mc²–v/c 曲线（相对论 γ 与牛顿 1 + β²/2 对比），点沿曲线上冲，v/c = 1 处渐近线；注明“m 不随速度变化，增长的是能量”。光子：标注 m = 0、E = pc、v = c，一个波包以 c 掠过。结尾：未来/过去光锥与 “c = 因果的速度极限”。

### 片尾要点
1. 光速对所有惯性观察者都相同
2. 运动的钟变慢，运动的尺沿运动方向缩短
3. 同时是相对的，时空间隔是绝对的
4. 双生子：惯性世界线的固有时最长
5. E = mc²，有质量的物体到不了光速

### 教授视角的自查与修正
- 不说“光速不能被超过是因为光最快”，而说 c 是时空本身的不变速度，光因无质量才以 c 运动。
- 避免“相对论质量随速度增大”：画面注明 m 不变，增长的是能量。
- 时间膨胀不是“看起来”慢：μ子数据、储存环、原子钟都是实测；同时强调“飞船内的人感觉一切正常”。
- 同时性的相对性已扣除信号传播时间，并非视觉延迟。
- 双生子：不说“加速度让人变年轻”，而说世界线是折线、换了惯性系；不对称性纯属狭义相对论范围。
- Hafele–Keating 包含引力效应，画面注明“狭义 + 广义”，字幕只说“验证了时间膨胀”（引力时间膨胀亦为时间膨胀）。
- μ子数值为单一速度的代表性估算，在核查表中注明简化假设。
- 伽利略叠加只在低速下近似成立（画面注明）。
