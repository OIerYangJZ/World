# 物理科普 · 一次讲透

五集中文物理科普动画，风格参考 3Blue1Brown 与 ScienceClic：深色背景、几何化动画、用可视化建立直觉。

- 画面：16:9 横屏，1920×1080，30 fps，H.264 + AAC（适合 B站 / 小红书）
- 音频：**纯背景音乐（无人声）+ 烧录中文字幕**。音乐由 `common/music.py` 用代码程序化合成，无版权问题。
- 每集另附 `字幕.srt`（与画面字幕逐条同步），可作外挂字幕上传。

## 制作流程（每集两个阶段）

1. **阶段一 · 物理内容**：`讲解稿.md` —— 章节结构、全部字幕旁白（与视频逐字一致）、画面设计说明，以及“科学事实核查”表（每条数值/论断的正确值与出处），并经过二次审读修订。
2. **阶段二 · 动画与渲染**：`scene.py`（manim CE 0.22）实现讲解稿；`common/build.py` 渲染 → 生成字幕 → 合成音乐 → 输出成品。

## 目录

```
物理科普/
├── common/
│   ├── style.py      # 配色、字体、字幕“节拍”系统（self.say）、标题/章节/片尾卡、SRT 输出
│   ├── music.py      # 程序化氛围音乐合成（和弦铺底 + 琶音 + 混响）
│   ├── build.py      # 一键构建：python common/build.py 01_黑洞 [--preview]
│   └── setup_env.sh  # 渲染环境安装（pango、Noto CJK 字体、LaTeX、manim）
└── 0X_主题/
    ├── 讲解稿.md     # 阶段一：讲解稿 + 科学事实核查
    ├── scene.py      # 阶段二：动画代码（class Video）
    ├── 字幕.srt      # 中文字幕
    └── 主题.mp4      # 成品视频
```

## 重新渲染

```bash
bash common/setup_env.sh                       # 首次
/opt/mvenv/bin/python common/build.py 01_黑洞   # 约 15–30 分钟/集（单核）
```
